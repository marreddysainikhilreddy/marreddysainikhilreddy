- 🤖 [AI-Image-Organizer-agent](https://github.com/marreddysainikhilreddy/AI-Image-Organizer-agent): an autonomous multimodal agent that runs local vision models through Ollama in a perception, reasoning, and action loop. Fully offline, zero cloud dependencies.
- 🧪 [LLM-Finetuning](https://github.com/marreddysainikhilreddy/LLM-Finetuning): reasoning distillation with QLoRA. Fine tuning Llama 3.2 3B on reasoning traces distilled from DeepSeek R1 using Unsloth and TRL, then exporting to GGUF and serving locally with Ollama.
- 🔎 [rag-agents](https://github.com/marreddysainikhilreddy/rag-agents): agentic RAG systems. A multi tool RAG agent with function calling across Wikipedia, Arxiv, and web retrievers, backed by FAISS vector search, plus advanced RAG techniques and local Llama inference.
- 🧠 Classic deep learning: [emotion classification](https://github.com/marreddysainikhilreddy/emotion-classification) with VGG16 transfer learning at 90.33% accuracy plus RoBERTa and BiLSTM text models, [facial keypoint detection](https://github.com/marreddysainikhilreddy/Facial-Key-Point-Detection-CNN), and [image captioning](https://github.com/marreddysainikhilreddy/Automatic-Image-Captioning) with a CNN and RNN encoder decoder.
